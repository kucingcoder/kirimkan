Kirimkan

Perangkat lunak opensource untuk mengirim pesan WhatsApp lewat API yang sepenuhnya gratis dan tanpa batas yang dapat digunakan dengan nomor Anda sendiri.

Github

Instalasi

  • Windows
    • Download program Kirimkan di link berikut Download
    • Ekstrak file zipnya
    • Jalankan program Kirimkan
    • Setelah muncul command line scan QR yang tampil
    • Tunggu hingga menyambungkan ke WhatsApp berhasil
    • Setelah berhasil buka browser dan cari http://127.0.0.1:7069, jika sudah ada websitenya maka API sudah berjalan
  • Linux Debian Based

    • Download file package .deb dengan perintah berikut, Sesuaikan dengan arsitektur CPU Anda

      Daftar arsitektur yang tersedia antara lain intel86 dan amd64

      wget /download/kirimkan-1.0-<arsitektur>.deb

    • Atur izin eksekusi dan lainnya dengan perintah berikut

      chmod 755 kirimkan-1.0-<arsitektur>.deb

    • Install Kirimkan dengan perintah dibawah ini dan tunggu hingga instalasi selesai

      sudo dpkg -i kirimkan-1.0-<arsitektur>.deb

    • Jalankan linux daemon/service Kirimkan dengan perintah berikut

      sudo systemctl start kirimkan

    • Untuk menampilkan QR yang akan di scan di WhatsApp jalankan perintah berikut lalu scroll kebawah dengan tombol page down hingga QR terlihat semuanya

      sudo systemctl status kirimkan
    • Scan QR lalu tunggu hingga menyambungkan ke WhatsApp berhasil
    • Setelah berhasil buka browser dan cari http://127.0.0.1:7069, jika sudah ada websitenya maka API sudah berjalan
  • Linux RedHat Based

    • Download file package .rpm dengan perintah berikut, Sesuaikan dengan arsitektur CPU Anda

    • Untuk menampilkan QR yang akan di scan di WhatsApp jalankan perintah berikut lalu scroll kebawah dengan tombol page down hingga QR terlihat semuanya

      sudo systemctl status kirimkan
    • Scan QR lalu tunggu hingga menyambungkan ke WhatsApp berhasil
    • Setelah berhasil buka browser dan cari http://127.0.0.1:7069, jika sudah ada websitenya maka API sudah berjalan

Ganti Nomor

  • Windows
    • Buka folder Kirimkan
    • Hapus file session.lock
    • Jalankan program Kirimkan
    • Setelah muncul command line scan QR yang tampil
    • Tunggu hingga menyambungkan ke WhatsApp berhasil
    • Setelah berhasil buka browser dan cari http://127.0.0.1:7069, jika sudah ada websitenya maka API sudah berjalan
  • Linux

    • Buka folder /etc/kirimkan dengan perintah berikut

      cd /etc/kirimkan

    • Hapus file session.lock dengan perintah berikut

      sudo rm session.lock

    • Mulai ulang daemon/service Kirimkan dengan perintah berikut

      sudo systemctl restart kirimkan

    • Untuk menampilkan QR yang akan di scan di WhatsApp jalankan perintah berikut lalu scroll kebawah dengan tombol page down hingga QR terlihat semuanya

      sudo systemctl status kirimkan
    • Scan QR lalu tunggu hingga menyambungkan ke WhatsApp berhasil
    • Setelah berhasil buka browser dan cari http://127.0.0.1:7069, jika sudah ada websitenya maka API sudah berjalan

Port Kustom

  • Windows
    • Buka file kirimkan.conf dalam folder kirimkan
    • Ubah API_PORT sesuai keinginan
    • Simpan file kirimkan.conf
    • Jalankan program Kirimkan
  • Linux

    • Buka file kirimkan.conf yang berada di /etc/kirimkan dengan perintah berikut

      sudo nano /etc/kirimkan/kirimkan.conf

    • Ubah API_PORT sesuai keinginan

    • Simpan file kirimkan.conf dengan menekan tombol ctrl + x kemudian y untuk menyimpan

    • Mulai ulang daemon/service Kirimkan dengan perintah berikut

      sudo systemctl restart kirimkan

    • Cek status daemon/service Kirimkan dengan perintah berikut. pastikan statusnya active dan sudah muncul 'Server API berjalan' sesuai dengan API_PORT di akhir log

      sudo systemctl status kirimkan

API

Format permintaan API Kirimkan seperti berikut

URL :

http://127.0.0.1:6969/kirim-pesan

Method :

POST

Body (JSON) :

{"No": "6285XXXXXXXXX", "Pesan": "pesanmu"}

Format respon API Kirimkan berhasil seperti berikut

Status :

200

Body (JSON) :

{"message":"Pesan berhasil dikirim ke 6285XXXXXXXXX", "status":"success"}

Format respon API Kirimkan gagal seperti berikut

Status :

400

Body (JSON) :

{"message":"pesan kegagalan", "status":"failed"}
